# Isabelle extraction

The real `torus_trace.ml` is generated by Isabelle/HOL code generation.
Run this in Isabelle (the theory that defines `state_trace`):

```isabelle
export_code state_trace in OCaml
  module_name TorusTrace
  file "extraction/torus_trace.ml"
```

The generated file defines the `TorusTrace` module (the octonion record
type + `state_trace`). `trace_export.ml` opens it and wraps it for the
FFI.

**Module name:** Isabelle writes the file as `torus_trace.ml`
(lowercase), but OCaml derives the module name from the file name, so
a lowercase file compiles to module `Torus_trace` and
`trace_export.ml`'s `open TorusTrace` fails with "Unbound module
TorusTrace". Rename the extraction output to `TorusTrace.ml` (capital
T) before building. The file in this directory is already named
`TorusTrace.ml` for that reason.
