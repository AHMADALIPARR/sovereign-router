# OCaml extraction

`TorusTrace.ml` is generated by the Isabelle session in `../isabelle`.
Regenerate it with `ISABELLE=/path/to/isabelle sh build.sh` from the repository
root. Isabelle checks the trace equations and exports
`Sovereign_Trace.Torus_Trace:code/TorusTrace.ocaml`; the build copies that output
to `TorusTrace.ml` for OCaml compilation. Do not edit the generated file.

The generated implementation uses Zarith integers. `ocaml/trace_export.ml`
registers a decimal-string interface with the Objective-C runtime, avoiding
OCaml tagged-integer narrowing across the foreign-function boundary.
